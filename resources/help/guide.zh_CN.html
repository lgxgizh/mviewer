MViewer 使用说明

图像算法工程师用的浏览 / 比较 / 分析工具。下面只写日常路径。

1. 浏览

  1. 打开一个图片目录（Ctrl+O）。缩略图会陆续出来。
  2. 单击看大图；Ctrl+单击 / Shift+单击多选。
  3. 滚轮缩放，双击在适应窗口和 100% 之间切换。

2. 比较（主路径）

  1. 在缩略图里选中 2–8 张图。
  2. 按 P 或 C 打开比较（也可用工具栏或右键菜单）。不足 2 张时状态栏会说明原因。
  3. 默认同步缩放和拖动。底部状态条显示 PSNR / SSIM。
  4. 模式（仅 2 张时）：B 闪烁 · S 左右分割 · W 滑动 · O 叠加 · K 棋盘格。需要时会出现叠加/棋盘格滑块。
  5. 勾选「显示差异」查看热力图；「对齐」在计算指标前做整数像素平移。
  6. 在图上右键拖画 ROI。每张图的选区旁显示该格 V 与 RGB 均值；完整表在检视面板。
  7. Esc：有选区先清框，再按退出。也可点「退出」。

4. 浏览窗口常用键

P / C打开比较（需 2–8 张）
Space当前图与下一张快速比较
F7分析面板（浏览窗口，单图；打开即出直方图。双图比较用比较模式）
I / M图片信息浮层
S幻灯片
Ctrl+R / Ctrl+Shift+H旋转 / 翻转并覆盖原文件
F1完整快捷键表
Ctrl+Shift+A取消选择
Ctrl+Alt+A批量分析导出

查看器全屏时，右键「分析」会先退出全屏，再在主窗口打开分析面板。分析面板只处理当前这一张图；两张图的 PSNR / SSIM 在比较模式里。

5. 双栏浏览

  • Ctrl+Shift+S 在右侧打开第二个图库；表头有后退 / 前进 / 上一级、浏览...、克隆左栏、交换和关闭。
  • 点击某一栏使其成为活动栏。删除 / 旋转 / 翻转作用于两栏的选择。
  • Ctrl+Alt+C 复制、Ctrl+Shift+M 移动活动栏的选择到另一栏的目录（Ctrl+Z 撤销；同名文件变为 name_1）。

6. USM 锐化对比

  • Ctrl+U 以最大化打开：左侧原图，右侧结果。选择预设或调整数量 / 半径 / 阈值。
  • 按住 Space 在鼠标所在侧查看另一侧；0 适应，1 100%，2 200%；Ctrl+C 复制，Ctrl+S 另存为。原图不会被覆盖。

7. RAW、文件与首选项

  • RAW 默认显示内嵌预览；Ctrl+Shift+D 解码完整 RAW。首选项 → RAW 显示可设置默认行为。
  • 删除进入回收站；Ctrl+Z / Ctrl+Y 撤销和重做删除、重命名、复制、移动、旋转和翻转。JPEG 旋转只修改 EXIF 方向标记。
  • 在全图查看器中，删除和 F2 只作用于当前显示的图像。
  • 工具 → 首选项：主题、语言（立即生效）、默认设置、确认、RAW 显示、自动检查更新。帮助 → 检查更新随时可用。
