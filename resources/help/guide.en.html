MViewer User Guide

A browse / compare / analyze tool for imaging algorithm engineers. Only the everyday paths are covered here.

1. Browse

  1. Open an image folder (Ctrl+O). Thumbnails appear progressively.
  2. Click to view large; Ctrl+click / Shift+click to multi-select.
  3. Scroll to zoom; double-click toggles between fit to window and 100%.

2. Compare (main path)

  1. Select 2–8 images in the thumbnails.
  2. Press P or C to open Compare (toolbar or context menu also work). With fewer than 2 images, the status bar explains why.
  3. Zoom and drag are synchronized by default. The bottom status strip shows PSNR / SSIM.
  4. Modes (2 images only): B Flicker · S Split · W Swipe · O Overlay · K Checkerboard. Overlay/checkerboard sliders appear when needed.
  5. Check Show Difference for the heatmap; Align uses an integer-pixel translation before metrics.
  6. Right-drag on an image to draw an ROI. Each pane shows its V and RGB means next to the selection; the full table is in the inspector panel.
  7. Esc: clears the selection first, press again to exit. You can also click "Exit".

When the viewer is full screen, the context-menu "Analyze" leaves full screen first and then opens the analysis panel in the main window. The analysis panel works on the current image only; two-image PSNR / SSIM lives in Compare.

5. Split browse

  • Ctrl+Shift+S opens a second gallery on the right; its header has back / forward / up, Browse..., Clone Left, Swap and close.
  • Click a pane to make it active. Delete / rotate / flip act on the selections of both panes.
  • Ctrl+Alt+C copies and Ctrl+Shift+M moves the active pane's selection to the other pane's directory (undo with Ctrl+Z; same-name files become name_1).

6. USM sharpen compare

  • Ctrl+U opens maximized: original on the left, result on the right. Pick a preset or adjust Amount / Radius / Threshold.
  • Hold Space to see the other side under the mouse; 0 fit, 1 100%, 2 200%; Ctrl+C copy, Ctrl+S save as. The original is never overwritten.

7. RAW, files and preferences

  • RAW files show the embedded preview by default; Ctrl+Shift+D decodes the full RAW. Preferences → RAW display sets the default.
  • Delete goes to the recycle bin; Ctrl+Z / Ctrl+Y undo and redo delete, rename, copy, move, rotate and flip. JPEG rotation changes only the EXIF orientation tag.
  • In the full viewer, Delete and F2 act on the displayed image only.
  • Tools → Preferences: theme, language (switches immediately), defaults, confirmations, RAW display, automatic update check. Help → Check for Updates works at any time.
