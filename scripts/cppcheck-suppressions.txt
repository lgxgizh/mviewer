# Goal: only flag real issues in our own src/ — never in system/Qt/STL headers.

# How this file is used (see .github/workflows/ci.yml -> cppcheck job):
#   cppcheck --enable=warning,performance,portability \
#            --inline-suppr --error-exitcode=1 \
#            --suppressions-list=scripts/cppcheck-suppressions.txt src
#
# Tuning: if cppcheck reports a false positive in OUR code, prefer a narrow
# inline `// cppcheck-suppress <id>` next to the code. Use this file only for
# system-include / global noise.
