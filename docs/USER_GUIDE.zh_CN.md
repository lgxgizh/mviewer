# MViewer 使用说明

[English](USER_GUIDE.md) | 简体中文

图像算法工程师专业视觉分析平台（Browse → Compare → Analyze → Report → Export → Workspace）。  
应用内快捷访问：**帮助 → 使用说明**（界面语言为简体中文时显示中文版）。完整按键表：**F1**。

---

## 1. 浏览模式（Browse）

1. **Ctrl+O** 打开图片目录，缩略图网格将异步加载显示。
2. **单击**看大图；**Ctrl+单击** / **Shift+单击** 多选。**Ctrl+Shift+A** 取消选择。
3. **视图缩放**：
   - 滚轮自由缩放；双击在「适应窗口」与 100% 实际大小间切换。
   - 画廊拥有焦点时，**Ctrl++** / **Ctrl+-** 调整缩略图大小，**Ctrl+Alt+9** 重置为默认。**Ctrl+0** 始终适应窗口。
   - 快捷预设（视图菜单）：**50%**、**100%**、**200%**、**400%**、**800%**（像素网格级）。
4. **几何变换**（覆盖原文件；JPEG 会按质量 95 重编码）：
   - **Ctrl+R** / **Ctrl+Shift+R**：顺时针 / 逆时针旋转 90° 并覆盖原文件。
   - **Ctrl+Shift+H** / **Ctrl+Alt+V**：水平 / 垂直镜像翻转并覆盖原文件。
   - 无选中图片时菜单项禁用，状态栏提示原因（不会静默无操作）。
5. **通道隔离与分析**：
   - **Shift+1…6**：原图 RGB / 红色 (R) / 绿色 (G) / 蓝色 (B) / 亮度 (Y) / 明度 (HSV-V)。
   - **Shift+C**：复制当前光标处像素颜色值（支持 Hex、RGB、Float 0-1、HSV 格式）。
6. **色彩管理 (CMS)**：
   - 「视图 → 色彩管理 (CMS)」：开启时按显示器 ICC 配置文件校色，关闭时直通 RGB（与 FastStone 行为一致）。
7. **动图与多帧容器**：
   - 支持 GIF、WebP 动画及多页 TIFF。
   - **Space** 播放/暂停，**←** / **→** 单帧步进。
8. **工作区与搜索**：
   - **F6**：专注浏览模式（隐藏侧边面板全屏看图）。
   - **Ctrl+Shift+F**：全局搜索面板。
   - **F7**：算法分析面板（即时计算直方图、统计分布与质量指标）。面板只分析当前这一张图；两张图的对比在比较模式。
   - 查看器全屏时，右键「分析」会先退出全屏，再回到主窗口打开该面板。

## 2. 比较模式（Compare）

1. **进入比较**：
   - 在缩略图里选中 **2–8 张**图片，按 **P** 或 **C** 进入比较模式（选不够 2 张时状态栏提示原因）。
   - 单张浏览时按 **Space** 可与下一张图进行快速原位对比。
2. **双图核心比较模式**（仅 2 张时）：
   - **B** 闪烁比较（Blink）
   - **S** 左右分割比较（Split）
   - **W** 卷帘滑动比较（Swipe/Wipe）
   - **O** 叠加透明比较（Overlay）
   - **K** 棋盘格交错比较（Checkerboard）
   - 叠加透明度与棋盘格大小滑条随模式激活自动呈现。
3. **差异与对齐分析**：
   - **H**：高亮差异热力图。
   - 底部状态栏实时计算并显示图像间 **PSNR / SSIM** 指标。
   - 点击「对齐」可在计算指标前按整数像素平移配准。
4. **感兴趣区域（ROI）交互**：
   - 在图像上 **按住右键拖动** 绘制感兴趣区域（ROI）。
   - 右键按下后不拖动再松开，会打开窗格菜单（可「导出此图调优结果...」）；拖动仍绘制 ROI。
   - 框顶显示基准标识（A / B），HUD 实时显示该区域的像素均值、方差、极值与直方图。
   - 支持多级同步框选与 TSV 测量数据导出。
5. **临时换图与布局**：
   - 按住 **1–8** 在鼠标所在窗格临时预览第 N 张图，松开恢复。指针不在窗格上时用当前焦点窗格，否则第 1 格。超出张数只提示。布局预设用 **Ctrl+2 / Ctrl+4 / Ctrl+8**。**Ctrl+1** 为 100% 实际大小，**0 / Ctrl+0** 为适应窗口。
6. **同步与协同**：
   - **Z** / **D**：切换同步缩放 / 同步平移拖拽。
   - 工具操作行「适合窗口 (F)」（分析、导出报告旁；快捷键 **F** / **Ctrl+0**）：勾选「统一像素倍率」时所有窗格用同一倍率适配；不勾选时各窗格按自身分辨率适配窗口，相同视野的图显示为相近大小。临时切换、闪烁或换图后仍保持该屏幕大小。
   - **R**：同步十字准星定位。
   - **L**：像素连线标注（对比不同图中对应位置的像素 RGB 及 Δ 差值）。
   - **X**：交换 A / B 视图窗格。
   - 比较的两张图在浏览器中手动选择；比较模式内不再提供上一组 / 下一组切换。
   - **Esc**：存在 ROI 选区时优先清除选区，再次按 Esc 退出比较模式。
7. **比较中的旋转 / 翻转是预览**：
   - 侧栏按钮或 **Ctrl+R** / **Ctrl+Shift+R** / **Ctrl+Shift+H** / **Ctrl+Alt+V** 只改当前窗格显示，**不覆盖原文件**。
   - 目标窗格优先为已点选的编辑窗格，否则为光标所在窗格 / 锁定基准；没有目标时状态栏提示，不会默默改第 1 格。
8. **每格调优与导出**：
   - 调整面板可为当前窗格单独设置亮度、对比度、伽马、白平衡，以及 USM 锐化（数量 0%–500%，半径 0.1–20 px，阈值 0–255，可选仅亮度）。默认关闭。预览、差异和直方图使用同一套调优，**不覆盖原文件**。「重置调整」会一并关闭 USM。
   - 「导出此图调优结果...」（窗格右键菜单或调整面板）按全分辨率把当前窗格的亮度/对比度/伽马、白平衡、USM、旋转/翻转和裁剪写入新的 PNG 或 TIFF。默认文件名为 `<原名>_adjusted.png`，保存在源文件旁边，或上次导出的目录。

## 3. 批量处理与报告导出（Batch & Export）

1. **批量格式转换与重命名**：
   - 按 **Ctrl+Shift+B** 打开批量处理对话框。
   - 支持格式转换（PNG、JPEG、WebP、TIFF 等）、批量缩放、色彩空间转换与灵活重命名模板。
2. **批量算法分析导出**：
   - 按 **Ctrl+Alt+A**（或在画廊右键菜单选择「批量分析导出」）。
   - 自动遍历选中图片运行当前激活的 Analyzer 算法流水线，结果一键输出 CSV / TSV。
3. **专业分析报告**：
   - 「文件 → 导出报告...」：生成包含原图预览、差异热力图、ROI 统计及 PSNR/SSIM 图表的独立 HTML 报告。
4. **导出图片中的图像元数据清单**：
   - 「文件 → 导出图片...」里的「图像元数据清单 CSV / JSON / HTML」写出每张图的文件名、尺寸和通道均值，不是上面的分析报告。
   - 选这些模式或「复制到剪贴板」时，格式、质量、缩放、水印、裁剪和重命名不再出现。清单仍要选输出目录；剪贴板不写文件，因此不需要输出目录。

## 4. 工程与工作区持久化（Workspace & Project）

1. **工作区保存与打开**（`.mvws`）：
   - 保存当前打开目录、选中的比较图像集合、ROI 区域坐标及分析器状态。
   - 支持跨机器或会话快速恢复工作现场。
2. **工程文件**（`.mvproj`）：
   - 保存完整数据集根目录集合、多组工作区以及定制的算法评估流水线配置。
3. **异常退出自动恢复**：
   - 若程序意外关闭或崩溃，下次启动时将自动检测未闭合的恢复标记并提示一键恢复上次现场。

## 5. 界面语言

- **工具 → 首选项... → 界面语言**：跟随系统（默认）、English 或简体中文。
- 语言会立即在已打开的窗口中生效；少数对话框在下次打开时更新。

---

## 6. 双栏浏览

- **视图 → 双栏浏览**或 **Ctrl+Shift+S** 在右侧打开第二个图库。右栏表头有后退 / 前进 / 上一级按钮、路径框、**浏览...**、**克隆左栏**（右栏显示左栏目录）、**交换**（交换两栏的目录和选择）以及关闭按钮。
- 点击某一栏使其成为活动栏；活动栏有高亮边框，状态栏显示该栏的信息。
- **Delete**、旋转和翻转作用于两栏选择的并集。
- **编辑 → 复制到另一栏**（**Ctrl+Alt+C**）和**移动到另一栏**（**Ctrl+Shift+M**）把活动栏的选择送到另一栏显示的目录。两栏显示同一目录时这两项不可用。确认框会写明来源栏和目标目录（可在首选项中关闭）。同名文件保存为 `name_1.ext`。通过菜单进行的复制和移动可以用 **Ctrl+Z** 撤销。
- **F6** 切换专注浏览模式（隐藏侧栏，让图库占满窗口）。

---

## 7. USM 锐化对比

- 选中一张图后按 **Ctrl+U**（或**工具 → USM 锐化对比...**）。对话框以最大化打开，左侧为原图，右侧为锐化结果。
- **预设模板**提供几种起点（通用标准、轻度细节增强、人像肤色保护、风光建筑清晰度、强边缘增强）；修改数量、半径或阈值后切换为**自定义**。**仅锐化亮度通道**可以避免彩色镶边。
- 按住 **Space** 时，鼠标所在的那一侧显示另一侧的图像；松开恢复。
- **0** 适应窗口，**1** 为 100%，**2** 为 200%。勾选**同步缩放/平移**时两侧保持同步。
- **Ctrl+C** 复制锐化结果；**Ctrl+S** 另存为新文件。原图不会被覆盖。

---

## 8. RAW 文件

- 默认显示 RAW 文件内嵌的预览 JPEG，速度快。状态栏会标明当前看到的是内嵌预览还是完整解码。
- **视图 → 解码完整 RAW**（**Ctrl+Shift+D**，查看器右键菜单中也有）对当前图像解码传感器数据；解码进行中再次执行即可取消。
- **首选项 → RAW 显示**可选：优先内嵌预览、预览小于传感器 90% 时完整解码、始终完整解码。

---

## 9. 文件操作

- **Delete** 把文件移入系统回收站。**Ctrl+Z** / **Ctrl+Y** 可撤销和重做删除、重命名、复制、移动、旋转和翻转；编辑菜单会显示将要撤销的操作。
- 旋转和翻转会**覆盖原文件**。对 JPEG，MViewer 优先只修改 EXIF 方向标记，像素和其他 EXIF 信息保持不变；其他格式会重新编码。可在首选项中开启确认，修改也可以撤销。
- 在全图查看器中，**Delete** 和 **F2**（重命名）只作用于当前显示的图像，而不是图库中的选择。

---

## 10. 排序与筛选

- 排序栏可按文件名、日期、大小、分辨率、类型、评分、相机或镜头排序；箭头按钮切换升序 / 降序。相同项按文件名排序。
- **搜索**按文件名筛选；**包含子文件夹**和**元数据**可以扩大搜索范围。
- **高级筛选**显示相机、镜头、ISO、标签、评分、旗标/颜色标签筛选以及文件类型筛选。**清除筛选** / **重置筛选**会清除所有条件。

---

## 11. 首选项

**工具 → 首选项...**

- **常规**：界面主题、界面语言（立即生效）、默认视图模式、默认排序、缩略图大小、幻灯片间隔和循环、删除 / 复制或移动 / 修改原图前确认、GPU 渲染、色彩管理、自动检查更新、RAW 显示。
- **比较**：比较窗口的默认设置。
- **分析**：默认分析叠加（斑马纹、伪彩色、单通道）和斑马纹阈值。

---

## 12. 更新检查

- 开启**启动时自动检查更新**后，MViewer 会在启动几秒后检查新版本，只有存在新版本时才显示不打断操作的提示。
- **帮助 → 检查更新...** 随时可以手动检查，即使关闭了自动检查。
- 提示中的**跳过此版本**会隐藏该版本，直到有更新的版本发布。

---

## 13. 同一按键在不同窗口中的含义

| 按键 | 浏览 | 查看器 | 比较 | USM |
|---|---|---|---|---|

| **Ctrl+1** | 网格视图模式 | 网格视图模式（图库） | 100% 实际大小 | — |
| **R** | — | 切换 ROI 框选模式 | 同步十字线 | — |
| **Ctrl+R** | 顺时针旋转 90°（写入文件） | 顺时针旋转 90°（写入文件） | 预览旋转当前窗格（不写文件） | — |
| **Space** | 与下一张快速比较 | 快速比较（动图：播放/暂停） | 按住显示另一侧 | 按住显示另一侧 |
