# MViewer 使用说明

图像算法工程师用的浏览 / 比较 / 分析工具。应用内也可打开：**帮助 → 使用说明**。完整按键表：**F1**。

## 浏览

1. **Ctrl+O** 打开图片目录，缩略图会陆续出现。
2. 单击看大图；**Ctrl+单击** / **Shift+单击** 多选。
3. 滚轮缩放；双击在「适应窗口」和 100% 之间切换。
4. **Alt+H** 打开分析面板（默认直方图，打开即计算）。

## 比较（主路径）

1. 在缩略图里选中 **2–8 张**图。
2. 按 **P** 或 **C** 进入比较（也可点工具栏「比较」，或右键「比较」）。  
   选不够 2 张时，底部状态栏会说明原因。
3. 默认同步缩放和拖动。窗口底部显示 **PSNR / SSIM**。
4. 仅 2 张时可用模式：
   - **B** 闪烁 · **S** 左右分割 · **W** 滑动 · **O** 叠加 · **K** 棋盘  
   叠加透明度和棋盘块大小的滑条，只在对应模式打开时出现。
5. 「显示差异」打开热力图；「对齐」可在算指标前自动对齐。
6. 在图上 **右键拖** 画 ROI。黄框上方标 **A / B**，右下角统计也是 A 一行、B 一行。
7. **Esc**：有选区先清框，再按退出。也可点「退出比较」。不要关启动时弹出的 CMD 窗口（关掉等于退出程序）。

## 比较窗口快捷键

| 键 | 作用 |
|---|---|
| **Z** / **D** | 同步缩放 / 同步拖动 |
| **Space**（按住） | 在 A 窗格临时看 B |
| **H** | 差异高亮 |
| **R** / **L** | 同步准星 / 像素连线 |
| **X** | 交换 A/B |
| **F** | 全部适应窗口 |
| **PgUp** / **PgDn** | 上一对 / 下一对 |
| **?** | 底部快捷键提示 |
| **Shift+1…5** | 通道 RGB / R / G / B / Y |
| **Esc** | 清 ROI 或退出比较 |

## 浏览窗口快捷键

| 键 | 作用 |
|---|---|
| **P** / **C** | 打开比较（需 2–8 张） |
| **Space** | 当前图与下一张快速比较 |
| **Alt+H** | 分析面板 |
| **I** / **M** | 图片信息浮层 |
| **S** | 幻灯片 |
| **←** / **→** | 上一张 / 下一张 |
| **F1** | 完整快捷键表 |

比较窗口里 **P 不再表示上一对**（请用 PgUp），避免和浏览里的「P = 比较」冲突。
