## 5. Performance risks (documented, mostly non-blocking)

1. 24 MP JPEG cold decode ~3.5 s / 4 K TIFF ~2.1 s on the 2-core VM
   (single-threaded decode, off UI thread; hardware-proportional).
2. 100 MP first-viewport ~1480 ms on VM (B10 report-only; regression axis is
   `--regression` ±10%).
3. Thread oversubscription on low-core machines (scheduler sizes to
   `idealThreadCount`; recorded proposal `max(1, cores-1)` — not implemented).
4. GPU Stage A opt-in only (`MVIEWER_GPU=1`); CPU tile path is the default.

## 8. Closure addendum (2026-08-09)

This addendum records post-baseline closure without rewriting the historical 2026-08-08 snapshot
or its 70/70 gate result.

- The UpdateChecker coverage gap is closed by the offline `updatechecker_tests` target and a
  Qt-free `FetchFn` injection seam. The regression covers canonical GitHub URL construction,
  standard JSON and escapes, dotted-version ordering and overflow, transport/parse errors,
  custom endpoints, and safe release-link policy.
- Release links from JSON are accepted only as absolute HTTPS URLs. A missing or rejected link is
  derived only for the canonical GitHub Releases API endpoint; custom endpoints never fabricate a
  GitHub link.
- The update launch path now names and explicitly consumes the `QFuture` returned by
  `QtConcurrent::run`, closing the baseline C4858 warning without changing task lifetime behavior.
- Targeted Debug verification passed `updatechecker_tests` on 2026-08-09. The subsequent full
  local gate passed 71/71 CTest tests, including `version_consistency`, `workflow_ux_tests`,
  `golden_image`, `bench_smoke`, and `bench_enforce`.
- Export destination safety now has test-first coverage for the dialog's edited output directory,
  source-equals-destination, batch duplicate destinations, hard-link aliases, and Windows ordinal
  case collisions. The runner rejects the entire conflicting batch before decode or write.
- Existing outputs are committed from unique same-directory temporary files with platform atomic
  replacement semantics; commit failure no longer pre-deletes the prior destination.
- Windows export path boundaries now convert the API's UTF-8 strings explicitly to and from native
  UTF-16. A Release regression covers a Unicode source name, destination directory, rename suffix,
  reopen, `primaryOutput`, and temporary-file cleanup end to end.
- After the export-safety changes, the full local Release gate passed 71/71 again on 2026-08-09
  (224.76 s CTest time): `export_acceptance_tests` 0.14 s, `workflow_ux_tests` 3.86 s,
  `golden_image` 0.08 s, `bench_smoke` 84.30 s, and `bench_enforce` 199.93 s.
- The baseline's partially asserted histogram-overlay coverage gap is closed by direct
  `compare_acceptance_tests` regressions. Pane overlays repopulate after layout, navigation,
  pane swaps, and Blink rebuilds; Blink hides whole pane containers and keeps engine/UI state
  synchronized during active rebuilds; main and pane histograms share adjusted-image and ROI
  scope, including with the side panel hidden or per-pane overlays enabled.
